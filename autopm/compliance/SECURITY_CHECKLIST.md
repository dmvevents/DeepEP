# Security & Compliance Checklist
- [ ] Field-level encryption for SSN and PII (AES-256; envelope keys).
- [ ] TLS/HTTPS in prod; scoped, time-boxed URLs for file access.
- [ ] Immutable AuditEvent on: credit pull, rule toggles, overrides, doc approvals, pre-approval publish, scenario gen.
- [ ] Access logs and least-privilege roles.
